# Justavideo

![PowerShell](https://img.shields.io/badge/PowerShell-%235391FE.svg?style=for-the-badge&logo=powershell&logoColor=white) ![Shell Script](https://img.shields.io/badge/shell_script-%23121011.svg?style=for-the-badge&logo=gnu-bash&logoColor=white)

Justavideo is an interactive video downloader that lives in your terminal, lets you download videos from a link, and helps you choose the resolution you want with simple arrow-key controls. Paste a video URL, select from all available qualities, and save the finished video directly to your Downloads folder — all through one clean command. Use justavideo in your terminal, PowerShell, or Command Prompt.

## Get started
> [!NOTE]
> Installation via terminal. Use one of the recommended methods below.

For more installation options, uninstall steps, and troubleshooting.

1. Install Justavideo:

    **MacOS/Linux (Recommended):**
    ```bash
    curl -fsSL https://cloud.ryz.wtf/install.sh | bash
    ```

    **Windows (Recommended):**
    ```powershell
    irm https://cloud.ryz.wtf/install.ps1 | Rex

2. Open terminal or cmd and run `justavideo`.
