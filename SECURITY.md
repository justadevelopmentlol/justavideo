# Security Policy
Thank you for helping us keep justavideo secure!

## Reporting Security Issues

The security of justavideo is our top priority. We appreciate the work of security researchers acting in good faith in identifying and reporting potential vulnerabilities.

If you'd like to report security vulnerabilities, please contact us on [telegram](https://t.me/justaskidlol) or [discord](https://discord.com/users/444624204147458079).
